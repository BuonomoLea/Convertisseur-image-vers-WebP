## Outil pour générer un fichier WebP prêt à télécharger en 3 étapes.

- Upload 1 fichier
- Convertir en Webp
- Télécharger

Aucune dépendances.

Fichiers accepté: JPG, JPEG, PNG, SVG
Disponible également en application installable (PWA).
